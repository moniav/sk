# Archive

> Superseded or retired docs kept for historical reference. Nothing here is current.

**Last updated:** YYYY-MM-DD
**Lifecycle:** archived

Docs land here instead of being deleted when they're no longer accurate but worth keeping
for history. `/sk:docs-audit` **exempts** this folder from orphan and staleness checks.

## How to archive a doc

1. Move the file here (keep its name; optionally prefix with the year).
2. Set its `Lifecycle: archived`.
3. Remove its link from the live index it used to sit in.
